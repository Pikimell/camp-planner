# Camp Planner

Демо: [camp-planner-eight.vercel.app](https://camp-planner-eight.vercel.app)

Camp Planner допомагає організувати туристичний похід: перетворює список учасників, меню, рецепти й продукти на узгоджений план.

## Що вирішує застосунок

- формує меню на кожен день;
- обчислює загальну кількість продуктів;
- створює список покупок;
- розподіляє продукти між учасниками;
- генерує графік чергувань;
- показує, у кого забирати кожен продукт;
- дозволяє вручну редагувати автоматично створені плани.

## Основні модулі

Учасники, продукти, страви й рецепти, меню, Duty Scheduler, розподіл продуктів і Food Pickup Plan.

Мета — зменшити ручну роботу, уникнути плутанини з продуктами та зробити відповідальність кожного учасника зрозумілою.
